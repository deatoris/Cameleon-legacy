3) Caméléon dev kit
The dev kit is a vailable using QT SDK & the generator project in project/devkit/generator (this is a Caméléon *.cm project file).

4) Source code
If you need to have access to the Population source code, please go to Population web site (http://www.population-image.fr).
If you need to have access to the Caméléon source code, please send-us your request describing your open source project from here: http://www.shinoe.org/cameleon/contact/.
The source code will be publicly available as soon as we can!

5) Third Party Dictionaries
The lib directory contain the first external Caméléon dictionary based on QCustomPlot (see here: http://www.workslikeclockwork.com). This dictionary is activated by default.

6) Linux Launch
On Linux/Unix, you need to install qtcreator and glut:
	sudo apt-get install qtcreator
	sudo apt-get install freeglut3
You should now be able to execute the file as normal. You can do this from the command line by typing:
	./cameleon.sh.

7) Windows Launch
Double click on cameleon.bat at the root directory
