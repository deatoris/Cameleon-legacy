MANPAGE
lcm manual - version 2.2.1

NAME
lcm

SYNOPSIS
lcm [*.cm file][composition options][-h]

DESCRIPTION
lcm is the Cameleon composition launcher (Lanceur de Composition in french). The launcher allows the user to launch a Cameleon composition, a workflow designed as a *.cm input file.

OPTIONS
lcm example.cm
lcm example.cm message="hello world!" occures="10"
lcm example.cm -h
lcm -h
